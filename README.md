# cs50-cash-credit
CS50 Week 1 - Cash and Credit problem set implementation in C.
CS50 – Cash and Credit

Overview

This repository contains my work on the Cash and Credit problem set from Harvard University's CS50 Introduction to Computer Science course.

Projects

1. Cash

An implementation that calculates the minimum number of coins required to provide a given amount of change.

Concepts practised:

- Greedy algorithms
- Loops and conditional statements
- Integer arithmetic
- User input validation

2. Credit

An implementation that validates credit card numbers using the Luhn algorithm and identifies the card issuer.

Concepts practised:

- Algorithms
- Modulo and integer division
- Loops and conditional statements
- Input validation
- Mathematical logic

Programming Language

C

Course

CS50 – Introduction to Computer Science, Harvard University.
